## 0.2.0 - 2026-08-10

- Added a reproducible local MoonBit quality gate and documented its supported toolchain behavior.
- Hardened trie and Double Array Trie boundary behavior.
- Added trainable HMM segmentation models and shared Unicode token policy.
- Added sentence, metric, and document-pipeline APIs.
- Added configurable extractive summaries with validation and redundancy control.
- Added deterministic CLI output, runnable HMM and document-pipeline examples, and a workload smoke harness without timing claims.
- Added maintainer, architecture, API, acceptance, and third-party notice docs.

This release is published to Mooncakes as `ppyq882/moonnlp` version `0.2.0`.
